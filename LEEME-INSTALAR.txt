ULIMA APP - INSTALAR EN IPHONE (SIN MAC, NO VENCE)
==================================================

Archivos que van en GitHub (los 6, NO este LEEME):
  index.html, manifest.webmanifest, sw.js, icon-180.png, icon-192.png, icon-512.png

PRIMERA VEZ
1. github.com -> repositorio público -> Add file -> Upload files -> arrastra los 6 archivos -> Commit changes.
2. Settings -> Pages -> Branch: main, carpeta / (root) -> Save.
3. En el iPhone abre https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/ en Safari
   -> Compartir -> Agregar a pantalla de inicio -> Agregar.
4. Ábrela siempre desde el ícono.

PANEL OCULTO (para la profesora)
  Menú lateral -> Ayuda -> toca 5 veces seguidas el título "Ayuda" (arriba, al centro).
  Contraseña: 123. Ahí se cambian alumno, cursos, colores, horario, asistencia y notas
  con sus pesos. El promedio final se muestra siempre entero (0.5 sube: 17.5 -> 18).

GESTOS (como en la app real)
  - Horario: desliza a la izquierda o derecha para cambiar de día (o usa las flechas).
  - Para volver: desliza desde el borde izquierdo de la pantalla (o toca la flecha).
  - Menú lateral: se cierra tocando afuera o deslizándolo a la izquierda.

ACTUALIZAR CUANDO HAYA CAMBIOS
  Sube de nuevo los 6 archivos al mismo repositorio (Add file -> Upload files -> Commit).
  En el iPhone abre la app con internet, ciérrala del todo y vuelve a abrirla.
  Los cambios hechos en el panel oculto se conservan.

NOTA: el repositorio es público; no pongas datos personales reales en la app.
